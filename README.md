# Nova Lab — B2B Microelectronics & Workshop Services

Landing page y tarifario de maquila B2B para talleres de servicio técnico de reparación de celulares y computadoras.

## Características
- **Stack:** Astro v5 + React Islands + Tailwind CSS
- **Modo Dark Minimal:** Optimizado para carga rápida e identidad técnica
- **Tarifario interactivo:**
  - Filtro por Categorías (Microsoldadura, Swaps, Desbloqueos de Red, Cuenta Google & Mi)
  - Filtro por Modalidad (Remoto / Server vs Presencial / Mesa Quirúrgica)
  - Switch de Divisa instantáneo (Córdobas C$ / Dólares $)
  - Calculador de margen y ganancia sugerida para talleres
  - Integración directa con WhatsApp para recepción de equipos y servicios remotos

## Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
